DICOM Facile

Apri le immagini di un esame su qualsiasi dispositivo

Trasforma i file DICOM (.dcm) di TAC, risonanze, radiografie ed ecografie in un PDF e in immagini JPG, pronti da inviare.

I file restano sul tuo dispositivo. La conversione avviene dentro il browser: nessun caricamento su server, nessun account, nessun tracciamento. La pagina è bloccata in modo da non poter inviare dati.

Puoi scegliere più file .dcm insieme, oppure un file .zip con tutta la cartella.

Come fare su iPhone o iPad
  1. Apri l'app File e trova la cartella con le immagini dell'esame.
  2. Tieni premuto sulla cartella e scegli Comprimi: si crea un file .zip.
  3. Torna qui, tocca Scegli i file → Sfoglia e seleziona il file .zip.

Se i file sono arrivati per email o WhatsApp, prima salvali nell'app File (“Salva in File”).

Come fare su Android
  1. Tocca Scegli i file e seleziona i file dell'esame (puoi selezionarne molti tenendo premuto).
  2. Se sono in una cartella compressa (.zip), scegli direttamente lo .zip.
Come fare su computer

Trascina in questo riquadro la cartella dell'esame (anche quella copiata dal CD), oppure usa Scegli una cartella.

Cosa ottengo?
  • Un PDF unico con una pagina di riepilogo e tutte le immagini, ordinate per serie.
  • Tutte le immagini in JPG, in un file .zip diviso per serie.
  • Gli eventuali referti PDF trovati tra i file.
